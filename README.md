# OpenCV Learning 🖥️📷

This repository contains my practice projects and experiments while learning **OpenCV with Python**.

I created these programs while following an OpenCV tutorial and exploring the basics of computer vision, image processing, video processing, and real-time camera operations.

## 📚 Topics Covered

- Reading and displaying images
- Working with images using OpenCV
- Reading and processing videos
- Working with a webcam
- Drawing shapes
- Mouse events
- Drag-and-drop interactions
- Real-time camera processing
- Writing and saving video output

## 🛠️ Tech Stack

- Python
- OpenCV
- NumPy

## 📂 Projects

### `DragAndDropRectangle.py`
A simple OpenCV project that uses mouse events to create and interact with a draggable rectangle.

### `LiveDirectDrawing.py`
A real-time drawing project using the webcam and OpenCV.

### `WorkingWithVideoInOpenCV.py`
Practice with reading, processing, and working with video using OpenCV.

### `test_camera.py`
A simple program for testing and accessing the webcam using OpenCV.

## 🎯 Learning Goal

The goal of this repository is to build a strong foundation in **Computer Vision and OpenCV** through hands-on practice.

More projects and experiments will be added as I continue learning.
